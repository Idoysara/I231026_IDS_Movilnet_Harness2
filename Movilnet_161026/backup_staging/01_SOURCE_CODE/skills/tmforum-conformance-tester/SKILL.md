# 🏛️ Skill: TM Forum Conformance Tester & Contract Validator

## 1. Propósito
Validar que todos los esquemas JSON, endpoints REST y respuestas de los microservicios de Movilnet IA cumplan estrictamente con las especificaciones técnicas oficiales de **TM Forum Open APIs**.

---

## 2. Contratos de Datos Telecom Estandarizados

| Código TM Forum | Nombre de la Especificación | Uso en Movilnet IA |
|:---|:---|:---|
| **TMF620** | Product Catalog Management API | Catálogo de planes 4GMAX, paquetes de datos y VAS. |
| **TMF678** | Customer Billing Management API | Estados de cuenta, saldos pendientes y facturas históricas. |
| **TMF680** | Recommendation API | Motor de recomendación inteligente de planes ante falta de datos. |
| **TMF632** | Party Management API | Información de identidad y perfiles de los 4M de abonados. |
